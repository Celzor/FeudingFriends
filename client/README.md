# react backend with webpack and ts

## what you need

- nvm
- node 18
- yarn

## running dev

`yarn install`
`yarn start`

## doing tests

# install playwright

`yarn install`
`yarn playwright install`
`yarn test`

or watch it
`yarn run test:watch`

# generate tests

start the servicers locally, this helps genrate tests

`npx playwright codegen http://localhost:3011/`
`npx playwright codegen https://feud.tgxn.net/`
