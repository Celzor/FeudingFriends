
# do first

- install nvm (under windows it's published here: https://github.com/coreybutler/nvm-windows/releases/tag/1.1.12)

- install npm/node @ v 18
```sh
nvm install 18
nvm use 18
```

- install yarn
`npm install -g yarn`


# install

- install dependencies
`yarn install`

# run

- start redis in docker compose
`docker-compose up`

- run server
`yarn start`
