# overview

host creates room, gets invite link
there is a host and x (2-16) players
how many rounds (6 default) (acceptible 2-32)
players choose name in lobby

they are split into teams (auto/host sets this up)
users join a hosts game with a room ID.

there is a leaderbord of runnign scores along bottom of ui

host chooses next round



## each round.

questions are shown to all teams

teams get a question and have to type the answer
the host gets to choose who got the question right
get it wrong, get an x...

next team chooses, answers are displayed as they are chosen

host has to choose which answer




## end of game

after rounds are over, the teams scored are totalled, and displayed

room back to lobby
